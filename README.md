# Minipad Next

[![Build](https://github.com/AlstarKnight/minipad-next/actions/workflows/build.yml/badge.svg)](https://github.com/AlstarKnight/minipad-next/actions/workflows/build.yml)

一个按热键就弹出来的悬浮多标签笔记本。使用体验参考 minipad2,代码是全新写的(没有用 minipad2 的源码),基于 [Tauri 2](https://tauri.app)。

- 全局热键(默认 Ctrl+M)呼出 / 隐藏,窗口小巧、默认置顶
- 拖到屏幕边缘自动贴边隐藏,鼠标碰到边缘再滑出来
- 多标签页,自动保存,每页就是一个普通的 `.md` 文件
- 所见即所得的富文本编辑:看到的就是排好版的样子,文件里还是普通的 Markdown
- 标签下面有格式栏(可以选显示哪些按钮、拖动调整顺序,也可以收起),选中文字也有小工具栏,`# `、`- `、`**粗体**` 这些写法打完就变样
- 字体颜色(也有渐变色)和背景颜色
- 一键切换深色 / 浅色,强调色可以换(纯色或渐变色)
- 所有能选颜色的地方共用一个颜色库:纯色和多节点渐变都能自己调、存进去、拖动排序,常用的拖进快捷色
- 列表按 Enter 自动接上,Tab 缩进,Ctrl+Enter 勾选任务,F5 插入当前日期时间(和记事本一样)
- 笔记本:每个子文件夹是一个笔记本,可以换图标和颜色;先选笔记本,再在标签页之间切换
- 标签放不下时可以一排滚动、展开成多行或收进侧拉的页面列表,也能像 Edge 那样给标签分组
- 长页面可以开悬浮目录;窗口也能缩成一个可以随意拖动的悬浮小图标
- 每天自动把笔记文件夹备份成 zip,保留最近 14 份
- 代码块是一张卡片:标题和语言点一下就能改,带行号、高亮、折叠和复制按钮
- 当前页面里查找和替换(区分大小写、全字匹配、正则表达式),全部页面搜索
- 笔记文件夹放在网盘里时,同一页两边都改过会另存一页“冲突副本”,哪边的修改都不丢
- 可以从 minipad2 导入原来的笔记,分组变成笔记本
- 深色模式、开机启动、托盘图标

每个版本改了什么见 [CHANGELOG.md](CHANGELOG.md)。

## 一、下载安装

- **正式版本**:在 [Releases](https://github.com/AlstarKnight/minipad-next/releases) 页面下载 `Minipad-Next-版本号-setup.exe`(安装版)或 `Minipad-Next-版本号-portable.exe`(免安装,直接运行)。
- **最新构建**:每次推送代码后,[Actions](https://github.com/AlstarKnight/minipad-next/actions/workflows/build.yml) 里对应那次运行的页面底部有 `minipad-next-windows` 压缩包,里面是同样的两个文件(需要登录 GitHub 才能下载)。

程序没有数字签名,第一次运行时 Windows 可能提示“已保护你的电脑”,点“更多信息”再点“仍要运行”即可。

## 二、使用说明

### 呼出和隐藏

| 操作 | 效果 |
| --- | --- |
| **Ctrl+M**(全局,任何程序里都能用) | 呼出窗口;窗口已经在前面时再按一次就隐藏 |
| **Esc** | 隐藏窗口(有搜索框、设置面板、笔记本列表或对话框打开时先关掉它们) |
| 窗口右上角 ✕ | 隐藏到托盘,不会退出 |
| 左键点托盘图标 | 显示 / 隐藏 |
| 右键托盘图标 | 显示 / 隐藏、打开笔记文件夹、退出 |

热键可以在设置里改。如果 Ctrl+M 和你常用的软件冲突(比如 OneNote 里 Ctrl+M 是新窗口),换成 Ctrl+Alt+M 之类的组合即可。启动时如果热键已经被别的软件占用,程序会提示你去设置里换一个。

拖动窗口:拖顶栏或底部状态栏的空白处;按住 **Alt** 在编辑区里也能拖,正常点击和打字不受影响。

### 贴边隐藏

把窗口拖到屏幕的**上边、左边或右边**贴住，鼠标离开窗口大约半秒后，窗口会缩到屏幕外，只留下可点击的贴边标识。默认显示“细线＋箭头”，鼠标碰到线段或箭头所在的位置就会展开；线条调短后，旁边透明的空白区域不会误触发。

- **贴边样式**：细线＋箭头（默认）、仅细线、细线＋鼠标靠近时弹出的按钮、只有箭头。仅箭头模式无细线，唤出区域在中央箭头附近。
- **细线粗细和长度**：粗细 1–12px（默认 2px），长度为边长的 10%–100%（默认 100%），也能切换为固定的 24–600px（两种方式各记各的长度，固定长度在高 DPI 屏幕上跟着缩放），顶部、左右三边均可调，设置内可预览。短线以边的中点为中心缩放。
- **颜色与微光**：细线和箭头默认跟随强调色，也可改纯色或渐变色。微光开关默认关闭，对四种样式都生效，开启后依然只露出原来的细线宽度，不会多出大片透明触发范围。微光是静态效果，无闪烁动画。
- 窗口滑出来以后,只要你在里面**打过字**,鼠标移开也不会缩回去,等你点到别的窗口时才缩。只是看一眼(不打字)的话,鼠标一移开就缩回去。
- 窗口缩进去以后按 Ctrl+M,也能直接把它叫出来。
- 有多块显示器时,只有外侧的边才会触发(两块屏幕相接的那条边不算)。窗口最大化时也不会触发。
- 不想要这个功能,可以在设置里关掉“靠屏幕边缘时自动隐藏”。

### 页面(标签页)

| 操作 | 效果 |
| --- | --- |
| **+** 按钮 或 **Ctrl+T** / **Ctrl+N** | 新建页面,建好后可以直接输入名字 |
| 双击标签 | 重命名 |
| 拖动标签 | 调整顺序 |
| 右键标签 | 重命名 / 移到别的笔记本 / 删除(打开标签分组时还有分组的几项) |
| **Ctrl+W** | 删除当前页面(会先确认) |
| **Ctrl+Tab** / **Ctrl+Shift+Tab** | 下一个 / 上一个页面 |
| **Ctrl+1 ~ Ctrl+8** | 跳到第 1~8 个页面 |
| **Ctrl+9** | 跳到最后一个页面 |
| 在标签栏上滚动鼠标滚轮 | 页面多的时候左右滚动标签 |

删除的页面不会真正删掉,而是移到笔记文件夹里的 `.trash` 文件夹(其他笔记本的页面在 `.trash` 下同名的文件夹里),想找回的话把文件拖回原来的文件夹即可。

#### 标签放不下时

标签的名字总是完整显示,不会被压短。页面多、标签栏放不下时,在设置的“外观 → 标签栏”里选一种方式:

- **一排滚动**(默认):标签排成一排,用鼠标滚轮左右滚;还有标签藏着的那一端会淡出去。放不下时标签后面多一个写着页面数的按钮,点开是全部页面的列表,可以打字筛选,回车或点一下就换过去。淡出和这个按钮都可以关掉。
- **点击展开成多行**:平时还是一排,点标签后面的按钮,全部标签在顶栏下面铺开成几行,选了页面就收回去(点别处或按 Esc 也会收回)。最多显示几行可以选(2~8 行),再多就在里面上下滚。
- **侧拉的页面列表**:顶栏只显示当前页的名字,点它(或顶栏左边的列表按钮)从窗口左边拉出页面列表,名字长的会换行;列表上方可以筛选,选了页面列表就收回去。可以改成从右边拉出、调宽度(140~360 像素),还可以设置成鼠标移到窗口那一边的边缘就拉出来。点列表上的图钉可以钉住,一直开在编辑区旁边(窗口太窄时自动变回侧拉)。

#### 标签分组

在设置的“外观 → 标签分组”里打开(默认关闭),像 Edge 浏览器那样把几页放进一个分组:

- 右键标签选“添加到新分组”,接着给分组起个名字、从颜色库里挑个颜色(纯色或渐变色,见下面的“颜色库”);名字可以不起,只显示一个颜色点。
- 分组的名字显示在组里第一个标签前面,组里的标签下面有一条组的颜色(也可以选整个标签淡淡染上组的颜色)。
- 点分组的名字折叠 / 展开;折叠后只留当前页面的标签,名字后面显示有几页。换到折叠的分组里的页面时会自动展开。
- 右键分组的名字可以改名字和颜色、在这个分组里新建页面、折叠、取消分组(取消分组只是把页面放回来,不会删页面)。
- 右键标签可以移到别的分组或移出分组;把标签拖到组里的标签旁边也就进了这个分组。在组里的页面上新建页面,新页面也在这个组里。
- 三种标签栏方式下都能用;在侧拉的页面列表里,分组的名字在组里的页面上面。
- 分组跟着笔记本存在 `.minipad.json` 里;关掉分组功能时分组还留着,再打开就回来了。

### 笔记本

页面多了可以分成几个笔记本,先选笔记本,标签栏里就只显示这个笔记本的页面。

| 操作 | 效果 |
| --- | --- |
| 点顶栏最左边的笔记本图标(鼠标移上去会显示笔记本的名字),或按 **Ctrl+B** | 打开笔记本列表,点一个就切换过去;也可以用 ↑ ↓ 选、Enter 切换 |
| 列表里的“新建笔记本…” | 输入名字,建好后直接切过去 |
| 列表里的“管理笔记本…” | 打开笔记本管理:换图标和颜色,也能新建、改名、删除笔记本 |
| 右键列表里的笔记本(或选中后按 F2 / Delete) | 改名 / 删除笔记本 |
| 右键标签 → “移到笔记本…” | 把这个页面移到别的笔记本,那边有同名页面时自动加编号 |

- 每个笔记本就是笔记文件夹里的一个子文件夹,里面的 `.md` 文件是它的页面。直接放在笔记文件夹里的页面属于「默认」笔记本,所以升级以后原来的页面都在「默认」里,不用搬文件。
- 笔记本管理里,左边是全部笔记本,右边给选中的笔记本挑图标(书本、文件夹、工作、爱心、星星、灵感、代码、书签)和颜色:默认跟随强调色,也可以从颜色库里选纯色或渐变色(见下面的“颜色库”)。图标和颜色存在这个笔记本文件夹的 `.minipad.json` 里。
- 每个笔记本记得自己的标签顺序和上次看的页面,下次启动会回到上次用的笔记本。
- 「默认」笔记本就是笔记文件夹本身,不能改名或删除。删除别的笔记本时,整个文件夹会移到 `.trash`,需要时可以找回。
- 只有一层:笔记本文件夹里再建的子文件夹不会显示。名字以 `.` 开头的文件夹(比如 `.trash`、`.git`)不算笔记本。
- 在资源管理器里新建、删除笔记本文件夹也可以,切回窗口时会同步过来。

### 编辑

编辑区是所见即所得的:标题、粗体、列表、表格、代码块直接显示成排好版的样子,不用切换模式。每个页面在文件里还是普通的 Markdown(`.md`),别的编辑器照样能打开。

- 每个页面有自己的撤销记录:切到别的页面再切回来,**Ctrl+Z** / **Ctrl+Y** 照样能撤销 / 重做这一页的修改(**Ctrl+Shift+Z** 也能重做)。
- **Enter** 开始新的一段,**Shift+Enter** 在段落里换行。
- 文件里段落中间的单个换行,在编辑区里也显示成换行,存回去还是一个换行。

**用 Markdown 的写法打字**,打完就变样:

| 输入 | 变成 |
| --- | --- |
| 行首 `# ` / `## ` / `### ` | 大标题 / 二级标题 / 三级标题 |
| 行首 `- ` 或 `* ` | 列表 |
| 行首 `1. ` | 编号列表 |
| 行首 `> ` | 引用 |
| ```` ``` ```` 或 ```` ```js ```` 再按 Enter | 代码块 |
| `**粗体**`、`*斜体*`、`~~删除线~~`、`` `代码` `` | 粗体、斜体、删除线、行内代码 |
| 行首 `---` | 分隔线 |

**格式栏**:标签下面的一排按钮,从左到右是撤销 / 重做、正文和标题(下拉选)、粗体、斜体、删除线、行内代码、链接、字体颜色、背景颜色、列表、编号列表、任务、引用、代码块、表格、分隔线、查找(在这一页里查找和替换)。按钮会跟着光标亮起来,显示当前的格式。窗口窄的时候放不下的按钮会换到第二行。

- 格式栏右边的“自定义”按钮(两条滑杆的图标)可以勾选要显示哪些按钮,不常用的去掉,格式栏就短一些。按住一行上下拖动可以调整按钮的顺序,竖线分隔也能拖动或去掉;“恢复默认”回到原来的顺序。
- 右边的箭头,或者顶栏的格式栏按钮(一个带工具条的小窗口图标,在搜索按钮左边),可以收起 / 打开整条格式栏;设置里也有这一项。程序会记住你的选择。
- 列表、编号列表按钮:不在列表里时变成列表;已经是这种列表时取消;是另一种列表时换过来。
- 表格和分隔线插在光标所在那一段的后面。

**字体颜色和背景颜色**:选中文字,点格式栏上的 A(字体颜色)或荧光笔(背景颜色)按钮,从颜色库里选一种颜色(纯色或渐变色,见下面的“颜色库”);选“默认颜色” / “无背景”去掉。没选中文字时选颜色,接下来打的字就是这个颜色。按钮下面的色条显示当前文字的颜色。颜色在文件里存成 HTML:

```
<span style="color: #df2a3f">红色的字</span>
<span style="background-color: #fbe9a6">黄色背景</span>
<span style="color: #5fb4ff; background-image: linear-gradient(90deg, #5fb4ff, #d66cf0); -webkit-background-clip: text; background-clip: text; -webkit-text-fill-color: transparent">渐变色的字</span>
```

**选中文字的悬浮按钮**:选中一段文字,文字上面会出来一排常用格式的按钮,不用再去点格式栏:正文 / 标题(下拉选)、粗体、斜体、删除线、行内代码、链接、字体颜色、背景颜色(颜色和格式栏上的一样,也有渐变色)。格式栏开着时也会出来。显示哪些按钮、顺序、在文字上面还是下面、只在格式栏收起时才出来或者干脆关掉,都在设置的“编辑 → 悬浮工具栏”里改。也可以用快捷键:

| 快捷键 | 作用 |
| --- | --- |
| **Ctrl+B** | 选中了文字时加粗;没选中时打开笔记本列表(和以前一样) |
| **Ctrl+I** | 斜体 |
| **Ctrl+E** | 行内代码 |
| **Ctrl+Alt+1** ~ **Ctrl+Alt+6** | 第 1~6 级标题,**Ctrl+Alt+0** 变回普通段落 |
| **Ctrl+点击链接** | 用系统浏览器打开(直接点链接是把光标放进去,方便改字) |

**代码块**是一张卡片:

- 顶栏左边是折叠按钮和标题,右边是语言和复制按钮(复制整段代码,不带行号)。
- 标题和语言**点一下就能改**:没有标题时把鼠标移到卡片上会出现“添加标题”,点它输入,按 Enter 或点到别处就保存,Esc 放弃。
- 代码有语法高亮和行号,长行自动换行。`shell`、`sh` 按 bash 上色,命令名和 `-x` 这样的参数也会上色;没写语言或者语言不认识时会猜着上色。行号可以在设置里关掉。折叠以后顶栏显示一共几行。
- 代码块里按 Tab 插入制表符；默认在代码块末尾连续按三次 Enter 退出为正文，也可以随时按 **Ctrl+Enter** 在代码块下插入正文。退出方式可在「设置 → 编辑」调整。

在文件里,代码块的写法是 ```` ``` ```` 后面先写语言,再空一格写标题:

````
```python 打招呼
print("hello")
```
````

> 编辑器保存时会把 Markdown 的写法统一一下,比如 `*` 开头的列表变成 `-`、`===` 下划线的标题变成 `#`。只打开页面、不改内容的话文件不会被重写。

### 块管理和折叠块

- 将鼠标移到正文、标题、列表项、引用、代码块或表格,左侧显示拖动手柄。拖动可重排块,包括列表/引用/折叠块里的子块;点击或右键手柄打开块菜单,可在上/下方插入块、转换块类型、跨层级移动、创建副本或删除,Ctrl+Z 可撤销。
- 默认编辑区正文右键保留系统菜单(剪切、复制、粘贴)。可在设置里改成块菜单;选中文字时仍使用系统菜单,Shift+右键也可调出系统菜单。
- 表格在默认右键设置下也能通过手柄操作:先将鼠标移到目标单元格,再点击手柄,可对该行/列插入、复制、删除和移动。
- **折叠块**:在块菜单中选择“转换块类型 → 折叠块”,也可直接在文件里输入下面的 Markdown。点箭头展开/收起,点标题改名;折叠内容可以包含列表和嵌套引用。

```markdown
> [!fold]- 课件总结
>
> 重点一
>
> - 条目
```

- `[!fold]-` 代表收起,`[!fold]+` 代表展开。默认展开/收起会写入 Markdown;在“设置 → 编辑”关闭“把折叠状态写入 Markdown”后仅改变界面,不会保存折叠操作。只读页面可以展开查看,不会写文件。
- 查找或目录跳转命中收起的内容时会临时展开折叠块。
- “设置 → 编辑”另有**块管理开关**(默认开,关闭时恢复 14px 左边距和系统右键)、**编辑区右键菜单**(系统/块菜单,默认系统)、**代码块退出方式**(第三次 Enter/第二次 Enter/仅 Ctrl+Enter)和**折叠状态是否写入文件**。


### 列表和任务

| 操作 | 效果 |
| --- | --- |
| 在列表项里按 **Enter** | 接着写下一项(任务的下一项也是没勾选的任务) |
| 在空的列表项上按 **Enter** | 结束列表 |
| 在列表项里按 **Tab** / **Shift+Tab** | 这一项缩进一级(变成上一项的子项)/ 取消缩进 |
| **Ctrl+Enter** | 代码块中退出并在下方插入正文;普通列表项加任务方框、任务项勾选/取消勾选,普通段落变成任务,选中多项时逐项切换 |
| 点任务前面的方框 | 勾选 / 取消勾选 |

### 插入日期时间

在编辑区按 **F5**,会在光标处插入当前的日期时间,和 Windows 记事本一样。默认格式是 `H:mm yyyy/M/d`,插入的是 `13:45 2026/10/11` 这样的文字。

格式可以在设置里改,写法和 Windows 的日期格式一样(注意大小写:大写 `M` 是月,小写 `m` 是分):

| 写法 | 意思 |
| --- | --- |
| `yyyy` / `yy` | 年(四位 / 两位) |
| `M` / `MM` | 月(`MM` 不足两位时前面补 0,下同) |
| `d` / `dd` | 日 |
| `dddd` / `ddd` | 星期几(`星期日` / `周日`) |
| `H` / `HH` | 时(24 小时制) |
| `h` / `hh` | 时(12 小时制),一般和 `tt`(`上午` / `下午`)一起用 |
| `m` / `mm` | 分 |
| `s` / `ss` | 秒 |

其他字符原样插入。要插入这些字母本身时用引号括起来,比如 `'Time' H:mm` 插入的是 `Time 13:45`。几个例子(时间是 2026 年 10 月 11 日 13:45):

| 格式 | 插入的内容 |
| --- | --- |
| `H:mm yyyy/M/d`(默认) | `13:45 2026/10/11` |
| `yyyy-MM-dd HH:mm` | `2026-10-11 13:45` |
| `yyyy年M月d日 dddd` | `2026年10月11日 星期日` |
| `tt h:mm` | `下午 1:45` |

### 悬浮目录

页面长、标题多的时候,可以在设置的“编辑 → 悬浮目录”里打开悬浮目录(默认关闭):

- 编辑区右边会出现一列短线,每个标题一条,级别越低越短;正在看的那一节,它的短线是强调色。
- 鼠标移到短线上,原地展开成目录,列出这一页的标题;点一个标题,页面滚到那里,光标停在标题末尾。鼠标移开就收起来。
- 打字、换页、文件在别处被改过时,目录跟着变。没有标题的页面不显示目录。
- 设置里可以改:
  - **显示方式**:鼠标移上去才展开(默认),或者一直展开在编辑区旁边(这时正文让出一列;窗口太窄、放不下目录和正文时自动收起成短线)。
  - **位置**:编辑区右边(默认)或左边。
  - **显示到**:一级到六级标题,默认显示到三级。
  - **宽度**:140~360 像素,默认 200。
  - **展开时的背景**:不透明度 40%~100%,调低了能透过目录看到后面的字。
  - **当前标题的颜色**:默认跟随强调色,也可以选纯色或渐变色。
  - 上面有实时预览。

### 查找和替换、搜索

- **Ctrl+F** 在当前页面里查找:编辑区上方出来一个查找栏,边打字边找,找到的地方都会高亮,当前这一处颜色深一些,查找框里显示“第几个 / 一共几个”。Enter / Shift+Enter(或 **F3** / **Shift+F3**)跳到下一个 / 上一个,到头了从另一头接着找。查找框右边的三个开关:区分大小写(Alt+C)、全字匹配(Alt+W)、正则表达式(Alt+R)。格式栏最右边的查找按钮也能打开它;先选中一段文字再打开,就直接找这段文字。
- **Ctrl+H** 打开替换(或点查找栏左边的小箭头):替换框里按 Enter 替换当前这一处并跳到下一个,**Ctrl+Enter** 全部替换。全部替换算一步,Ctrl+Z 一次就能全部撤回。用正则表达式时,替换的文字里可以写 `$1`、`$2`(第几个括号里的内容)、`$&`(整个匹配)、`$<名字>`,`\n` 是换行,`\t` 是制表符。
- 查找栏开着时换到别的页面,那一页也按同样的条件高亮。Esc 关掉查找栏,光标停在刚才找到的地方;再按 Esc 才隐藏窗口。
- **Ctrl+Shift+F** 搜索所有笔记本里页面的内容和标题(顶栏的放大镜按钮也是它),结果里会标出页面在哪个笔记本。用 ↑ ↓ 选择结果,按 Enter 或点击结果会跳到对应页面(需要的话自动切换笔记本),并选中匹配的文字。
- 设置的“编辑 → 查找替换”里可以把 Ctrl+F 换成搜索全部页面(这时 Ctrl+Shift+F 在当前页面里查找)、把查找栏放到编辑区下方、换找到的地方的高亮颜色(默认跟随强调色,也可以选纯色或渐变色,有实时预览)。

### 保存和同步

- 输入时自动保存(停止输入约半秒后写入;一直打字不停时,最多 5 秒也会存一次),切换窗口、隐藏窗口、退出时也会保存。**Ctrl+S** 可以立刻保存。保存失败会自动重试。
- 底部状态栏左边是这一页的字数(只算看得到的字,不算 Markdown 符号),右边显示“保存中…”、“已保存”或保存失败的原因。
- 每个页面就是一个普通的 `页面名.md` 文件(UTF-8 编码),可以用任何编辑器打开,也可以用网盘同步。
- 文件在别处被改过(网盘同步、用其他编辑器改了),切回 Minipad Next 窗口时会自动读到新内容;在文件夹里新建或删除的 `.md` 文件也会变成或去掉对应的标签页。
- 如果这一页在这边也改过(两边都改了),默认两边都留着:别处的版本另存成同一个笔记本里的一页**冲突副本**,名字像 `周报 (冲突 2026-10-12 18.30)`,就放在原来那页后面;原来那页保留这边的内容。看过以后用不着的副本直接删掉就行。设置的“数据 → 同步冲突”也可以改成直接用这边的内容覆盖(0.3.0 以前的做法)。
- 直接拷进笔记文件夹的旧文件,即使是 GBK 编码或带 BOM 的,也能正常显示中文;保存时会存成 UTF-8。
- 页面文件读不出来(比如被杀毒软件或网盘占着)时,编辑区上方显示原因,这一页只读,其他页面照常;能读了会自动恢复。文件里有无法识别的字节(可能已经损坏)时照常显示内容,但也是只读,不会把乱码存回原文件。
- 设置文件 `settings.json` 损坏时,原文件改名成 `settings.json.bad-时间` 留着,能读出来的设置照常用,并提示一次。
- 页面顺序和当前页面记录在每个笔记本文件夹里的 `.minipad.json`;笔记文件夹里那份还记着当前打开的笔记本。

默认位置:

| 内容 | 位置 |
| --- | --- |
| 笔记 | 程序所在文件夹里的 `notes\` |
| 每日备份 | 程序所在文件夹里的 `backups\` |
| 设置(含窗口位置大小) | `%APPDATA%\io.github.alstarknight.minipadnext\settings.json` |

- 程序所在的文件夹不能写入时(比如装进了 Program Files),笔记和备份放在 `%APPDATA%\io.github.alstarknight.minipadnext\` 下的 `notes\`、`backups\`。
- 0.2.7 及更早的版本把笔记和备份放在 `%APPDATA%\io.github.alstarknight.minipadnext\` 下。升级后第一次启动会把它们复制到程序旁边,原来的文件留着;复制不成功就继续用原来的位置。
- 设置的“数据”里可以换笔记文件夹和备份位置,“打开笔记文件夹”“打开备份文件夹”直接打开它们;右键托盘图标也能打开笔记文件夹。

> 0.1.0 版本存在 `%APPDATA%\com.minipadnext.app\` 下。升级到 0.2.0 后第一次启动时会自动把那里的设置和笔记搬到新位置。

### 从 minipad2 导入

用过 minipad2 的话,可以把原来的笔记导进来:点笔记本列表里的“从 minipad2 导入…”(设置的“数据 → 导入”里也有),选 minipad2 的程序文件夹(或者它的 `data` 文件夹)。

- 支持 minipad2 3.2 的数据。更老的版本请先用 minipad2 3.2 打开一次,让它把数据升级。
- 选好文件夹后先显示里面有多少分组和页面,再选怎么导入:
  - **每个分组建一个笔记本**(默认),分组里的分组也是单独的笔记本,名字像 `工作 › 项目`;不在分组里的页面放进一个叫 `minipad2` 的笔记本(名字可以改)。也可以**全部放进一个笔记本**。
  - **保留高亮**:minipad2 里画下划线的高亮变成文字颜色,其余的变成背景色,颜色和 minipad2 里设置的一样。
  - **备忘录、链接、通讯录、文字模板、快速链接**:每个整理成一页(默认导入)。
  - **剪贴文字**:全部放进一页,每条一个代码块(默认不导入)。
  - **回收站里的页面**:放进单独的“minipad2 回收站”笔记本(默认不导入)。
  - **跳过空白的页面**(默认跳过)。
- 导入只会新建笔记本,已有的笔记不会被改动;和已有的笔记本重名时自动加编号。导入前会照常做当天的自动备份。
- 页面里的文字原样保留:`# `、`- `、`1. ` 开头的行,`*星号*`、`_下划线_` 这些不会变成标题、列表或粗体;网址会变成可以 Ctrl+点击打开的链接。
- 数据里有读不懂的地方(比如文件被截断)时,能读的部分照样导入,读不懂的地方会在导入窗口里列出来。

### 每日备份

每天第一次保存(包括新建、改名、删除、移动页面和笔记本)时,程序会在后台把整个笔记文件夹打包成一个 zip,比如 `笔记备份 2026-10-11.zip`,不影响正在写的内容。

- 默认放在上表的 `backups` 文件夹,保留最近 **14** 份,更早的自动删掉(只删程序自己生成的 `笔记备份 日期.zip`,不会动你放在那里的其他文件)。
- zip 里是笔记文件夹的全部内容,包括所有笔记本、`.minipad.json` 和 `.trash`;`.git` 这类以 `.` 开头的其他文件夹不打包。
- 要找回内容,解压对应日期的 zip,把需要的 `.md` 文件拷回笔记文件夹即可。
- 备份出错时(比如备份位置的磁盘满了)会在窗口底部提示一下。当天不会反复重试,改了备份设置或重启程序以后会再试一次。

### 颜色库

能选颜色的地方(强调色、贴边标识、悬浮图标、查找高亮、目录高亮、笔记本图标、标签分组、字体颜色和背景颜色)用的都是同一个颜色库,在一处改了,别处也跟着变。默认有 15 种纯色和 9 种渐变色,最多能存 128 个。

- **收起时**只显示快捷色,点一下就用这个颜色;点 **＋** 展开整个颜色库,展开后点 **−** 收起。
- **展开后**分成「快捷（收起时显示）」「纯色」「渐变色」三块,每个颜色只出现一次。拖动色块调整顺序,焦点在色块上时按 **Shift+←/→** 也行;纯色和渐变色之间不能互相拖。
- **快捷色**:把颜色拖进快捷区就多一个快捷色,拖回它的分类就少一个,别的颜色不会被挤出去或补进来,默认 5 个。想限制个数,在设置的“外观 → 快捷色上限”里填,空着表示不限;到了上限,再拖进来的颜色换掉最后一个快捷色。快捷色只剩 1 个时也能拖出去,由下一个颜色补上。
- **改颜色**:双击、右键色块或按 **F2**,就能修改库里的这个颜色。点“自定义颜色 / 渐变节点”(设置里叫“自定义…”)可以调一个新颜色:纯色或渐变;渐变能设角度,有 2~7 个颜色节点,每个节点的颜色和位置(0~100%)都能改,上面有预览。“应用颜色”用在这里,“保存当前颜色”(设置里叫“保存”)把它存进颜色库。
- **删颜色**:展开后鼠标移到色块上,点右上角的 ×;删错了点“撤销删除”。自定义面板里的“恢复默认颜色”把颜色库换回默认的那些。改掉或删掉库里的颜色,已经用上的地方不会变。
- 颜色库和快捷色的个数存在设置文件里。旧版的“我的颜色”和笔记本颜色预设会自动并进来。

### 设置

点顶栏的齿轮按钮打开设置(旁边的太阳 / 月亮按钮可以直接在浅色和深色之间切换)。

设置分成 5 类,点左边的分类,右边只显示这一类,每一类里用小标题分开;焦点在分类上时,用方向键(Home / End)也能换。保存和取消一直在最下面,在几类里改的东西点一次“保存”就都存下了。下次打开设置,会停在上次看的那一类。分类默认放在左边,可以在“外观”里换到上面;窗口很窄时会自动放到上面。保存时出了错(比如热键被占用、文件夹不能用),错误显示在最下面,并且自动换到出错的那一类。

- **常规**
  - **呼出热键**:点输入框,然后直接按下想要的组合键(需要包含 Ctrl / Alt / Shift / Win 之一,F1~F12 可以单独用)。录热键的时候,原来的全局热键会暂时停用。
  - **开机启动**:开机后自动在托盘待命,不弹窗口。
  - **在任务栏显示**:默认不显示,只在托盘里。
  - **窗口总在最前**:顶栏的图钉按钮也能切换。
- **外观**
  - 主题
    - **外观**:跟随系统 / 浅色 / 深色。
    - **强调色**:活跃标签上面那条线、亮起来的按钮、勾选框、保存按钮等用的颜色。第一个色块是默认的橙色,其他的从颜色库里选,也可以自己调纯色或多节点渐变(见上面的“颜色库”)。
    - **快捷色上限**:颜色库收起时最多显示几个快捷色,所有颜色库通用;空着表示不限(最多 128)。改的时候颜色库马上跟着变,点“取消”就不保存;拖动快捷色不会改它。
    - **字号**:也可以用 **Ctrl+加号** / **Ctrl+减号** 调整。
    - **设置页面的分类**:放在左边(默认)还是上面,选了马上就能看到效果。
  - 标签栏
    - **活跃标签的高亮**:顶部线条(默认)、整个标签(整个标签染上强调色)或整圈边框。
    - **标签放不下时**:一排滚动(默认)、点击展开成多行、侧拉的页面列表,下面只显示选中的那种方式的选项,上面有预览。见上面的“标签放不下时”。
  - 标签分组:开关,组里的标签怎么标出来。见上面的“标签分组”。
- **窗口**
  - 贴边隐藏:开关(见上面的“贴边隐藏”);四种样式(细线＋箭头、仅细线、细线＋悬浮按钮、只有箭头);细线粗细(1–12px,默认2px)、长度(边长的 10%–100%,或固定的 24–600px)和预览;贴边颜色(纯色/渐变色/跟随强调色),以及适用于所有样式的微光开关(默认关闭)。
  - 悬浮图标:开启后顶栏多一个按钮,点了窗口缩成一个可以拖动的小图标。可以调大小、不透明度、单击还是双击打开,换成自己的图片,给图标上色;左边有实时预览。
- **编辑**
  - 编辑器
    - **标签下面显示格式栏**:默认显示,顶栏的格式栏按钮也能切换。
    - **代码块显示行号**:代码块左边的行号,默认显示。
    - **F5 插入的日期时间**:日期时间的格式,写法见上面的“插入日期时间”。输入框下面会实时显示现在按 F5 会插入什么;留空就用默认格式 `H:mm yyyy/M/d`。
  - 悬浮工具栏:选中文字时弹出悬浮按钮(默认)、只在格式栏收起时弹出、不弹出;在选中文字的上面(默认)还是下面;显示哪些按钮、拖动调整顺序,上面有预览,可以恢复默认。见上面的“选中文字的悬浮按钮”。
  - 悬浮目录:开关、显示方式、位置、显示到几级标题、宽度、展开时背景的不透明度、当前标题的颜色,见上面的“悬浮目录”。
  - 查找替换:Ctrl+F 是在当前页面里查找(默认)还是搜索全部页面;查找栏放在编辑区上方(默认)还是下方;找到的地方的高亮颜色。
- **数据**
  - **笔记文件夹**:留空就用默认位置(见上面的“保存和同步”);可以手动填写,也可以点“选择…”挑一个,比如 OneDrive 里的某个文件夹。勾着“更换文件夹时复制已有笔记”时(默认勾着),已有的笔记会复制到新文件夹(新文件夹要是空的,旧文件保留);不勾就直接读新文件夹里的笔记。
  - **同步冲突**:同一页两边都改过时,另存冲突副本(默认)还是直接用这边的内容覆盖。
  - **备份**:可以关掉每日自动备份、改保留份数(1~365),或者换一个备份位置(不能放在笔记文件夹里面)。这里还会显示最近一次备份的日期,点“打开备份文件夹”可以直接看备份。
  - **导入**:从 minipad2 导入。

设置面板底部显示当前版本号,点“GitHub”会打开项目主页。

## 三、自己构建

### 1. 准备环境(只需要做一次)

1. **Microsoft C++ 生成工具**:下载 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/),安装时勾选 **“使用 C++ 的桌面开发”**。
2. **Rust**:从 [rustup.rs](https://rustup.rs) 下载 `rustup-init.exe` 并运行,一路默认即可。装完重新打开终端,运行 `rustc -V` 能看到版本号就说明装好了。
3. **Node.js**:安装 [Node.js](https://nodejs.org) 的 LTS 版本(20 或更新)。
4. **WebView2**:Windows 10/11 一般已经自带,不用管。

### 2. 构建

在项目根目录(就是这个 README 所在的文件夹)打开 PowerShell 或命令提示符:

```powershell
npm install
npm run build
```

第一次构建要下载并编译 Rust 依赖,会花几分钟,之后就快了。`npm run build` 会先把前端用到的第三方库复制到 `src/vendor/`,并把编辑器 Milkdown 打包成 `src/vendor/milkdown.js`。

构建结果:

| 文件 | 说明 |
| --- | --- |
| `src-tauri\target\release\bundle\nsis\Minipad Next_版本号_x64-setup.exe` | 安装程序 |
| `src-tauri\target\release\minipad-next.exe` | 程序本体,可以直接运行 |

### 3. 测试

```powershell
cargo test --manifest-path src-tauri/Cargo.toml       # 单元测试:文件名、编码识别、笔记本、备份、贴边计算、设置等
npm run test:ui                                       # 界面测试:在浏览器里用模拟后端操作界面
cargo fmt --check --manifest-path src-tauri/Cargo.toml                            # 代码格式
cargo clippy --all-targets --manifest-path src-tauri/Cargo.toml -- -D warnings    # 代码检查
```

界面测试用 [Playwright](https://playwright.dev) 驱动 Chromium,第一次运行前需要装一次浏览器:`npx playwright install chromium`。

`scripts/smoke-test.ps1` 是 Windows 冒烟测试,会删掉本机 `%APPDATA%` 里的 Minipad Next 设置和笔记,所以平时只在 GitHub Actions 上自动运行。确实要在一台测试机上跑的话,加上 `-Force`:

```powershell
pwsh scripts/smoke-test.ps1 -Exe src-tauri/target/release/minipad-next.exe -Force
```

### 开发调试

```powershell
npm run dev
```

会以调试模式启动程序,改了 `src/` 里的前端文件后,在窗口里按 **Ctrl+R** 刷新即可看到效果;改了 Rust 代码会自动重新编译。

也可以运行 `npm run preview`,再用浏览器打开它显示的地址(默认 http://127.0.0.1:5173/)看界面。浏览器里用的是模拟后端(数据存在浏览器的 localStorage),热键、托盘、贴边隐藏这些系统功能不会生效。前端用了 ES 模块,直接双击 `src/index.html` 是打不开的。

图标的源文件是 `app-icon.svg`,改了以后运行 `npm run icons` 重新生成 `src-tauri/icons/`。

### 在 Linux 上交叉编译 Windows 版(可选)

```bash
sudo apt install mingw-w64 nsis libayatana-appindicator3-dev
rustup target add x86_64-pc-windows-gnu
npm install
npx tauri build --target x86_64-pc-windows-gnu
```

## 四、自动构建和发布

`.github/workflows/build.yml` 会在每次推送和每个 Pull Request 时:

- 在 Linux 机器上检查 Rust 代码格式,核对各处的版本号和 CHANGELOG,并跑界面测试;
- 在 Windows 机器上:
  1. 用 clippy 检查代码(有警告就算失败),跑单元测试;
  2. 构建安装包和免安装版;
  3. 真正启动程序做冒烟测试:窗口能不能出来、前端能不能读写笔记、全局热键、贴边隐藏、从 0.1.x 升级时的数据搬迁、空笔记本自动补一页、每日备份、重复启动只保留一个;
  4. 把两个 exe 上传成这次运行的构建结果;
- 上面都通过以后,合并到 main 时新版本自动发布 Release(见下)。

要发布新版本:把 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 里的版本号改好(`src-tauri/tauri.conf.json` 直接用 `package.json` 里的版本号,不用改;这几处对不上时构建会失败),在 `CHANGELOG.md` 加上 `## 版本号` 这一节,然后合并到 main。合并后格式检查、界面测试和 Windows 构建都通过了,如果这个版本还没有发布,会自动建标签 `v版本号`、发布 Release,并附上安装版和免安装版,Release 的说明就是 CHANGELOG 里这个版本的那一节。已经发布过的版本不会重复发布;上次发布到一半失败了(比如上传安装包出错),重新运行这次构建就会补上。

`CHANGELOG.md` 里没有这个版本的那一节时,构建会失败,提醒你补上。想手动发布也可以:推送一个 `v` 开头的标签,或者在 GitHub 的 Releases 页面点“Draft a new release”新建标签再发布,构建通过后同样会附上安装包。

## 六、已知限制

- 程序没有数字签名,第一次运行时 Windows 可能会拦一下(见上面的下载安装)。
- 笔记本只有一层:笔记本文件夹里再建的子文件夹不会显示。
- 只能运行一个 Minipad Next:再启动一次只会把已经开着的窗口叫出来,避免两个程序同时写笔记。
- 外部修改是在切回窗口时检查的;窗口一直在前台时,别处的修改要等下次切回来才会显示。
- 编辑器改过的页面,保存时 Markdown 的写法会统一一下(见上面的“编辑”),内容不变。
